# 文字風化シミュレーター / Text Erosion

文字が古い看板のように輪郭から欠け、細い接続が切れ、小さな破片が脱落していく過程を観察するWebアプリです。Vite・TypeScript・Canvas 2Dで実装しています。React、サーバー、データベース、外部APIは使用しません。

## 実行環境と開発

Node.js 20 と npm、Canvas 2D / Web Worker に対応する現行ブラウザを使用します。以下はすべて `apps/text-erosion` で実行します。

```bash
npm install       # 通常のインストール
npm ci            # CI・ロックファイルを厳密に再現するとき
npm run dev       # 開発サーバー
npm run build     # 型チェックと dist/ への本番ビルド
npm test          # Vitestによるアルゴリズムの単体テスト
npm run preview   # ビルド済みアプリの確認
```

## 操作

初期文字は「奥多摩湖」。入力を変更したり、明朝体・ゴシック体を切り替えたりすると文字形状を再生成します。日本語の変換確定後に計算し、複数行にも対応します。

進行度を0〜100%で調整します。0%では元の文字マスク、100%では完全な消滅を表示します。「パターンを再生成」は新しいシードで計算し、「進行度をリセット」はパターンを変えずに0%へ戻します。「PNGを保存」で、その時点の背景と青い文字を画像として保存します。入力文字はHTMLに埋め込まず、Canvasへの描画だけに使用します。

## アルゴリズム

1. 表示用とは別のCanvas（640×256）で文字を中央に収め、アルファ値128以上を二値マスクにします。
2. 背景までの正確なユークリッド距離を、1次元距離変換の行・列パスで計算します。画像外も背景と見なします。
3. 固定シードから生成した3スケールの連続値ノイズで距離抵抗を変化させます。細い接続は距離が浅いため先に壊れやすくなります。
4. 四近傍の輪郭から優先度キューで侵食を広げます。各ピクセルは、背景へ通じる経路が先に侵食されるまで消えません。単純なノイズ閾値と異なり、内部へ突然孤立した穴を作りません。文字の元からある穴も侵食境界になります。
5. 消滅時刻を1〜100%へ正規化し、20〜99%の順に連結成分を解析します。進行度・元の面積・成分サイズ・シードに応じて小さな破片を脱落させ、その時刻を上書きします。大きな破片は保持します。
6. 計算はWorkerで一度行い、スライダー操作では消滅時刻だけを参照します。破片脱落後も残存画素は単調減少し、逆再生で同じ状態が復元されます。古い入力のWorkerは中断します。

## 検証と制約

Vitestで原形保持、決定性、全進行度での単調性、消滅、空入力、背景への連結、細い橋の破断、小破片の脱落、距離変換を検証します。UIのE2Eテストは導入しません。

- フォントはOSの日本語フォント（Noto、游明朝／游ゴシック、ヒラギノなど）を使用します。日本語フォント未導入の環境では別途OSに用意してください。OS間で文字形状は異なります。
- 計算・PNGは640×256固定です。高DPIでも処理量は増えず、拡大時にはピクセルの縁が見えます。
- 進行度は1%刻み。欠損面積は線形ではなく、書体・文字・シードにより各段階の破断時期が変わります。
- 非常に長い文字列や多数の改行は、自動縮小によって読みにくくなることがあります。空白のみなら空の画像を表示します。
- パターンは現在の画面内で維持されます。シードや文字の永続保存・共有機能はありません。
- 素材、コケ、錆、3D、装飾的アニメーションは対象外です。物理的な重力・支持点の計算ではなく、視覚的な侵食モデルです。
- このアプリの公開・デプロイ設定は含めません。CIではビルドとテストを実行します。
